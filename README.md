# java-shareit

ShareIt — сервис для шеринга вещей: пользователи публикуют вещи, которыми готовы
поделиться, бронируют вещи друг друга и оставляют запросы на нужные им вещи.

## Модули

- **gateway** (порт 8080) — принимает запросы пользователей, валидирует входные
  данные и передаёт их дальше по REST.
- **server** (порт 9090) — содержит бизнес-логику приложения и хранит данные
  в PostgreSQL.

Модули общаются между собой по REST.

## Сборка

```
mvn clean verify -P check,coverage
```

Команда выполняется из корня репозитория и собирает оба модуля.

## Запуск

```
docker compose up -d
```

Поднимаются три сервиса: `gateway`, `server` и `postgres`.
